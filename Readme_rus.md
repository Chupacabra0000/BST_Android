# BST Android

Android-приложение для работы с **бинарным деревом поиска (Binary Search Tree, BST)** и его визуализации.

Проект демонстрирует реализацию обобщённого бинарного дерева поиска с поддержкой нескольких типов данных, индексированного доступа к элементам, удаления, балансировки, сериализации и графического отображения дерева.

## Возможности

* Реализация бинарного дерева поиска с нуля
* Поддержка нескольких типов данных:

  * `Integer`
  * `Date`
  * `Point2D`
* Добавление элементов в дерево
* Получение элемента по его индексу в порядке обхода `in-order`
* Удаление элемента по индексу
* Балансировка бинарного дерева поиска
* Графическое отображение дерева
* Отображение элементов дерева в виде отсортированного списка
* Сохранение данных дерева в локальный файл
* Загрузка данных из локального файла
* Сохранение состояния дерева при изменении конфигурации Android, например при повороте экрана

## Принцип работы

Приложение хранит данные в структуре **Binary Search Tree**.

Каждый узел дерева содержит:

* хранимое значение;
* ссылку на левый дочерний узел;
* ссылку на правый дочерний узел;
* ссылку на родительский узел;
* размер поддерева.

Размер поддерева позволяет эффективно находить элемент по его позиции в отсортированном `in-order` обходе дерева.

Например, для следующего дерева:

```text
        10
       /  \
      5    20
     / \
    2   7
```

`in-order` обход даст:

```text
2, 5, 7, 10, 20
```

Поэтому:

```text
get(0) → 2
get(1) → 5
get(2) → 7
get(3) → 10
get(4) → 20
```

## Поддерживаемые типы данных

### Integer

Целые числа обрабатываются с помощью `Integer.parseInt()` и сравниваются численно.

Пример:

```text
42
```

### Date

Даты представлены с использованием `java.time.LocalDate`.

Формат ввода:

```text
YYYY-MM-DD
```

Пример:

```text
2026-09-26
```

### Point2D

Двумерная точка представлена координатами `x` и `y`.

Поддерживаются следующие форматы:

```text
3,4
```

или:

```text
3 4
```

Точки упорядочиваются по их евклидову расстоянию от начала координат `(0,0)`.

Например, точка:

```text
(3,4)
```

имеет расстояние `5` от начала координат.

## Пользовательский интерфейс

Главный экран приложения содержит:

1. **Выбор типа данных** — определяет тип значений, хранящихся в дереве.
2. **Поле значения** — используется для ввода нового элемента.
3. **Поле индекса** — задаёт индекс элемента для операций `Get` и `Remove`.
4. **Add** — добавляет новое значение в дерево.
5. **Remove** — удаляет элемент по его индексу в `in-order` порядке.
6. **Get** — получает элемент по его индексу.
7. **Balance** — перестраивает дерево в более сбалансированную структуру.
8. **Save** — сохраняет текущие значения во внутреннее хранилище приложения.
9. **Load** — загружает ранее сохранённые значения.
10. **Визуализация дерева** — отображает BST в графическом виде.
11. **List** — показывает элементы в отсортированном `in-order` порядке.

## Основные классы

### `BinaryTree`

Содержит основную реализацию бинарного дерева поиска.

Основные операции:

```java
add(Object value)
insert(Object value)
get(int index)
remove(int index)
balance()
size()
toList()
firstThat(TestIt test)
saveTo(Writer writer)
loadFrom(BufferedReader reader, UserType type)
```

Класс также реализует интерфейс `Iterable<Object>` и предоставляет итератор для `in-order` обхода дерева.

### `Node`

Представляет отдельный узел дерева.

Каждый узел содержит:

```text
value
left
right
parent
size
```

Поле `size` содержит количество узлов в соответствующем поддереве.

### `BinaryTreeView`

Пользовательский Android `View`, отвечающий за графическое отображение дерева на объекте `Canvas`.

Рекурсивно отрисовываются:

* связи между узлами;
* узлы дерева;
* значения узлов.

Визуализация автоматически масштабирует дерево по вертикали при необходимости.

### `UserType`

Интерфейс, определяющий взаимодействие поддерживаемого типа данных с бинарным деревом.

Он предоставляет методы:

```java
typeName()
create()
clone(Object obj)
parseValue(String s)
getTypeComparator()
```

Благодаря этому различные типы объектов могут использовать одну и ту же реализацию `BinaryTree`.

### `UserFactory`

Регистрирует доступные типы данных и предоставляет соответствующую реализацию `UserType` в зависимости от выбранного пользователем типа.

В настоящее время поддерживаются:

```text
Point2D
Date
Integer
```

### `TreeViewModel`

Хранит текущее дерево и выбранный тип данных.

Использование Android `ViewModel` позволяет сохранять состояние дерева при изменении конфигурации приложения, например при повороте экрана.

### `MainActivity`

Связывает пользовательский интерфейс Android с реализацией бинарного дерева поиска.

Отвечает за:

* обработку пользовательского ввода;
* выбор типа данных;
* добавление элементов;
* удаление элементов;
* получение элементов по индексу;
* балансировку;
* сохранение;
* загрузку;
* обновление списка;
* обновление графического представления дерева.

## Балансировка дерева

Операция `balance()` сначала получает все значения с помощью `in-order` обхода.

Полученный отсортированный список затем рекурсивно преобразуется в сбалансированное дерево. Средний элемент выбирается в качестве корня, после чего аналогичным образом создаются левое и правое поддеревья.

Например:

```text
Отсортированный список:

1 2 3 4 5 6 7

        4
      /   \
     2     6
    / \   / \
   1   3 5   7
```

Такой подход позволяет уменьшить высоту сильно несбалансированного бинарного дерева поиска.

## Сохранение и загрузка

Приложение сохраняет значения дерева во внутреннем хранилище Android в файл:

```text
tree_data.txt
```

Каждое значение записывается на отдельной строке.

Например:

```text
1
5
7
10
20
```

При загрузке для преобразования сохранённых строк используется текущий выбранный `UserType`.

Поскольку файл содержит значения, но не содержит отдельного идентификатора типа данных, **перед загрузкой необходимо выбрать соответствующий тип данных**.

## Сборка проекта

Клонирование репозитория:

```bash

```

После этого откройте проект в **Android Studio**.

Дождитесь синхронизации Gradle и выполните сборку проекта.



## Пример работы

1. Запустите приложение.
2. Выберите тип данных `Integer`.
3. Введите значение, например:

```text
50
```

4. Нажмите **Add**.
5. Добавьте несколько дополнительных значений:

```text
30
70
20
40
60
80
```

6. Приложение отобразит получившееся бинарное дерево поиска.
7. Используйте **Get** с нужным индексом, чтобы получить элемент из отсортированного порядка.
8. Используйте **Remove**, чтобы удалить элемент по индексу.
9. Нажмите **Balance**, чтобы перестроить дерево в более сбалансированную структуру.
10. Нажмите **Save**, чтобы сохранить значения локально.
11. Нажмите **Load**, чтобы загрузить ранее сохранённые значения.
